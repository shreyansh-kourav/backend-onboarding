# Terminal & File Operations

Everything a backend developer does starts here. The goal is not memorising flags — it's knowing **what each command touches** and **which ones can't be undone**.

## Moving around

```bash
pwd                     # where am I (absolute path)
ls -la                  # all entries, long format, including hidden
ls -lah                 # ...with human-readable sizes
cd /var/log             # absolute path
cd app                  # relative to current directory
cd ..                   # one level up
cd -                    # back to the previous directory
cd ~                    # home
```

`ls -la` and `ls -al` are the same thing — flag order doesn't matter.

## Files and directories

```bash
mkdir logs              # one directory
mkdir -p src/app/api    # create the whole chain, no error if it exists
touch app.py            # create empty file / update mtime
cp file.txt copy.txt    # copy a file
cp -r src/ backup/      # copy a directory tree
mv old.txt new.txt      # rename
mv file.txt /tmp/       # move
rm file.txt             # delete — permanent, no trash
rm -r logs/             # delete a directory and its contents
```

`rm -rf` is `-r` (recursive) plus `-f` (force, never prompt). It is the most dangerous command in this list.

## ⚠️ `rm -rf` — what actually goes wrong

```bash
rm -rf $BUILD_DIR       # if BUILD_DIR is empty → rm -rf /  or  rm -rf $HOME
rm -rf *.log            # glob expands first; a typo like *.log/ changes the target
rm -rf /tmp/cache/      # trailing slash doesn't make it safer
```

Rules that prevent the disasters:

1. **Quote and guard variables:** `rm -rf -- "${BUILD_DIR:?refusing to run with empty BUILD_DIR}"`. The `:?` aborts when unset or empty.
2. **Look before deleting:** `ls -la target/` first, or use `rm -ri` (interactive) once.
3. **Never run it from a variable you just typo'd.** Write the glob out when practical.
4. `--` before a path stops it being read as a flag (protects against a file literally named `-rf`).

There is no undo. Version control saves tracked files; untracked work is gone.

## Reading files

```bash
cat app.py              # dump the whole file
less app.py             # scroll; q to quit, / to search
head -n 20 app.py       # first 20 lines
tail -n 50 app.log      # last 50 lines
tail -f app.log         # follow a growing log (Ctrl+C to stop)
```

## Finding things

```bash
grep -rn "TODO" src/            # recursive, with line numbers
grep -rn --include='*.py' "except" .
find . -name "*.env" -o -name ".env"    # by name
find . -type f -newermt '-1 day'        # modified in the last day
find . -type d -name "__pycache__" -exec rm -rf {} +
wc -l app.log                   # count lines
sort names.txt | uniq -c        # sorted counts of duplicates
file upload.bin                 # what the bytes actually are (magic bytes)
stat app.py                     # size, inode, permissions, timestamps
```

`find -exec ... {} +` is how you act on many files safely; `find ... -delete` exists but test it with `-print` first.

## Redirection and pipes

```bash
cmd > out.txt           # stdout to file, overwrite
cmd >> out.txt          # append
cmd 2> err.txt          # stderr to file
cmd > out.txt 2>&1      # both to the same file (> before 2>&1 matters)
cmd1 | cmd2             # stdout of cmd1 becomes stdin of cmd2
cmd | tee out.txt       # show it and save it
```

`>` truncates the target **before** the command runs — `cmd > app.log` on a log you're tailing destroys it even if `cmd` fails.

## Quoting and globs

| Form | Meaning |
|---|---|
| `"$VAR"` | Expand, keep as one argument (spaces survive) |
| `'$VAR'` | Literal — no expansion at all |
| `*.py` | Shell expands before the command sees it |
| `"*.py"` | Passed literally to the command |
| `\ ` | Escape a single special character |

Unquoted `$VAR` with spaces splits into several arguments — the cause of a large share of "why did this script delete the wrong thing" incidents.

## Quick reference

| Command | What it does | Watch out |
|---|---|---|
| `pwd` | Print working directory | — |
| `ls -la` | List, long, hidden | — |
| `cd` | Change directory | `cd` alone → home |
| `mkdir -p` | Create nested dirs | Silent success hides typos |
| `touch` | Create/update file | Also updates mtime of existing files |
| `cp -r` | Copy tree | Overwrites without asking |
| `mv` | Move/rename | Overwrites without asking |
| `rm` | Delete file | Permanent |
| `rm -rf` | Delete tree, forced | **No undo, no prompt** |
| `grep -r` | Search recursively | Use `--include` to avoid binaries |
| `find` | Locate by attribute | Test `-exec` with `-print` first |
| `tail -f` | Follow a log | `>` on that file wipes it |
| `file` | Identify by magic bytes | Trust this over extensions |
