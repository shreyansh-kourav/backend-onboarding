# List all files (hidden) with permissions

```bash
ls -al <dir>
```

The files will be listed as this:

```bash
lrwxrwxrwx   1 root root          8 Apr 22  2024 sbin -> usr/sbin
drwxr-xr-x   2 root root       4096 Mar 31  2024 sbin.usr-is-merged
drwxr-xr-x  24 root root       4096 Nov 17 11:26 snap
drwxr-xr-x   2 root root       4096 Sep 15 00:33 srv
-rw-------   1 root root 4294967296 Nov 17 00:16 swap.img
```

The columns are:

1. File type and permissions — `-rw-r--r--`
    - First character indicates the type: `-` regular file, `d` directory, `l` symbolic link, and others.
    - The remaining characters show read (`r`), write (`w`), and execute (`x`) permissions for the owner, group, and everyone else.
2. Hard-link count — `1`
3. Owner — `alex`
4. Group — `staff`
5. Size in bytes — `2048`
6. Last-modified date/time — `Nov 18 10:30`
7. Name — `notes.txt`  
    For a symbolic link, this may include `->` and the link’s target.

# Permission Categories

Permissions are assigned to three categories of users:

- **Owner**: The user who created the file or directory.
- **Group**: A set of users who share the same group as the file or directory.
- **Others**: All users who are neither the owner nor part of the group.

# Numerical Representation

Each permission type is assigned a numerical value:

- Read (`r`) = 4
- Write (`w`) = 2
- Execute (`x`) = 1

### Changing Permissions

To change the permissions of a file or directory using numerical values, you can use the `chmod` command. The syntax is `chmod <permissions> <file or directory>`.

```
chmod 755 myscript.sh
```
