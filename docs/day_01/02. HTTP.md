HTTP is a request-and-response protocol. The browser sends a request; the server (or a proxy/CDN acting for it) returns a response. In HTTP/1.1, the messages look text-like; HTTP/2 and HTTP/3 encode them differently, but the same basic concepts apply.

A simplified HTTP/1.1 request:

```http
GET /products?category=books HTTP/1.1
Host: shop.example
Accept: text/html
Cookie: session=...
```

- **Request line**: method (`GET`), path (including query string), and HTTP version.
- **Headers**: metadata such as the host, accepted response formats, cookies, and authentication information.
- **Blank line**: separates headers from the body.
- **Body**: optional data sent with the request. For example, a `POST` might carry JSON or form data.

A simplified response:

```http
HTTP/1.1 200 OK
Content-Type: text/html
Cache-Control: max-age=60

<html>...</html>
```

- **Status line**: HTTP version, numeric status code, and a short reason phrase.
- **Headers**: metadata about the response, such as its content type, caching rules, or a redirect destination.
- **Blank line**, then an optional **body**: the returned HTML, JSON, image data, and so on.

## 17 status codes you’ll commonly encounter

|Code|Meaning|Typical situation|
|---|---|---|
|200 OK|Request succeeded|A page or API response is returned|
|201 Created|A resource was created|An API successfully creates a new record|
|204 No Content|Succeeded, with no response body|An update or delete succeeds without returning content|
|301 Moved Permanently|Permanent redirect|A URL has a new permanent location|
|302 Found|Temporary redirect|The client is directed elsewhere for now|
|304 Not Modified|Cached copy is still usable|The browser can reuse its cached response|
|400 Bad Request|Request is invalid or malformed|Missing or invalid request data|
|401 Unauthorized|Valid authentication is missing or wasn’t accepted|Sign in, or provide valid credentials|
|403 Forbidden|The server refuses access|You’re authenticated—or identity isn’t the issue—but lack permission|
|404 Not Found|Resource not found, or its existence is concealed|Wrong URL or nonexistent item|
|405 Method Not Allowed|That method isn’t supported for this resource|`POST` sent to an endpoint that only accepts `GET`|
|409 Conflict|Request conflicts with the resource’s current state|A version conflict or duplicate operation|
|422 Unprocessable Content|Request is understood but its content can’t be processed|JSON is valid, but a field fails validation|
|429 Too Many Requests|Rate limit reached|Client sent requests too frequently|
|500 Internal Server Error|Unexpected server-side failure|Application hit an unhandled error|
|502 Bad Gateway|A gateway or proxy got an invalid response upstream|A proxy couldn’t get a usable response from another server|
|503 Service Unavailable|Service temporarily can’t handle the request|Overload or planned maintenance|
